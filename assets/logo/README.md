# Instella logo

Everything in this folder except this README is generated by `make-icon.py`: the logo as SVG
(`instella-icon.svg`, and `instella-icon-small.svg` simplified for 16–32 px), PNGs from 16 to
1024 px, and the multi-size `instella.ico`.

## Regenerating

The script needs Python 3 with numpy and Pillow (`pip install numpy pillow`). From the repository
root:

```
python assets/logo/make-icon.py assets/logo
```

The output is deterministic: an unchanged script rewrites identical files.

## Where the logo is used

The runtime embeds two files straight from this folder (`src/Instella.Installer.Runtime`
`.csproj`): `instella.ico` (fallback window icon) and `instella-icon-256.png` (default Welcome page
image). The rest are copies. Update them after regenerating:

| Copy | From |
|---|---|
| `assets/icon.png` (NuGet package icon) | `instella-icon-128.png` |
| `src/Instella.Server/wwwroot/favicon.ico` | `instella.ico` |
| `src/Instella.Server/wwwroot/favicon.png` | `instella-icon-32.png` |
| `src/Instella.Server/wwwroot/favicon.svg`, `logo.svg` | `instella-icon-small.svg` |
| `src/Instella.Server/wwwroot/logo-large.svg` | `instella-icon.svg` |
| `samples/SampleApp/Assets/icon.ico` | `instella.ico` |
